# Версии мода

Для каждой новой сборки мода сохрани её исходники отдельным коммитом и поставь уникальный тег версии. Отправь коммит и тег на origin. Для тестовых сборок используй тег с суффиксом -test.N.

В аннотации тега укажи, что изменилось, и SHA-256 собранного пакета. Сгенерированные пакеты остаются локальными, поскольку содержат файлы исходного TalkHammer.
